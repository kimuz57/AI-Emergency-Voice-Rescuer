## ข้อมูลตัวอย่าง (seed) — ใช้เฉพาะตอนพัฒนา

`cmd/seed` ใส่ข้อมูลตัวอย่างให้หน้าเว็บมีของให้ดู (แดชบอร์ด กราฟสถิติ ปฏิทิน ประวัติ)
และใช้ทดสอบ API ตามเล่ม server **ไม่เรียก** โปรแกรมนี้เอง ต้องรันด้วยมือเท่านั้น

### สิ่งที่สร้าง

| ข้อมูล | รายละเอียด |
|---|---|
| ผู้ใช้ 2 คน | แอดมิน 1 (`role=admin`) และผู้ดูแล 1 (`role=caregiver`) ยืนยันอีเมลแล้ว ล็อกอินได้ทันที |
| ผู้ป่วย 4 คน | ชื่อสมมติ ห้อง 101–104 มีอายุ เพศ และโรคประจำตัว ผู้ดูแลตัวอย่างถูกผูกกับทั้ง 4 คนใน `caregiver_patients` |
| อุปกรณ์ 4 ตัว | MAC `02:5E:ED:00:00:01`–`04` (locally administered ไม่ชนกับบอร์ดจริง) ผูกผู้ป่วยผ่าน `device_patients` พร้อมจุดติดตั้ง เปิดใช้งาน 3 ตัว ยังไม่เปิด 1 ตัว (`…:04`) |
| `detection_logs` | ย้อนหลัง 30 วันจากวันที่รัน วันละ 0–4 เหตุ กระจายหลายช่วงเวลา (กลางคืน/เช้า/ค่ำบ่อยกว่า) เฉพาะอุปกรณ์ที่เปิดใช้งาน เหตุล่าสุด 2 รายการ **ยังไม่ปิด** (ขึ้นบนแดชบอร์ด) ที่เหลือปิดแล้วภายใน 1–25 นาที |
| ไฟล์เสียง | `audio_recordings/seed-*.wav` 8 kHz 2 วินาที เป็นเสียงสังเคราะห์ (ไม่ใช่เสียงคน) ให้ปุ่มเล่นเสียงในหน้าประวัติทำงานได้ |

### วิธีรัน

1. เปิด PostgreSQL (Redis ไม่จำเป็นสำหรับ seed)

   ```powershell
   docker compose --env-file backend/.env up -d postgres   # รันจากโฟลเดอร์ราก
   ```

2. ตั้งรหัสผ่านของบัญชีตัวอย่างใน `backend/.env` (ไฟล์นี้ไม่ถูก commit) — **ไม่มีรหัสผ่านฝังในโค้ด**
   ไม่ตั้งแล้ว seed จะหยุดทันที

   ```env
   SEED_ADMIN_PASSWORD=...        # อย่างน้อย 8 ตัวอักษร
   SEED_CAREGIVER_PASSWORD=...
   # ไม่บังคับ (default admin.seed@example.com / caregiver.seed@example.com)
   SEED_ADMIN_EMAIL=
   SEED_CAREGIVER_EMAIL=
   ```

3. รัน

   ```powershell
   cd backend
   go run ./cmd/seed
   ```

   แล้วล็อกอินหน้าเว็บด้วยอีเมล/รหัสผ่านข้างบน

### รันซ้ำ

- รันกี่ครั้งก็ได้ ไม่สร้างข้อมูลซ้ำ: ผู้ใช้ค้นจากอีเมล ผู้ป่วยจากชื่อ + ห้อง อุปกรณ์จาก MAC
  ของที่มีอยู่แล้วจะถูกข้าม (ไม่เปลี่ยนรหัสผ่าน role หรือสถานะเปิด/ปิดของอุปกรณ์ที่กดไว้ระหว่างทดสอบ)
- `detection_logs` ตัวอย่างมี `audio_url` ขึ้นต้นด้วย `/api/audio/seed-` ถ้ามีอยู่แล้วจะข้ามทั้งชุด
- ข้อมูลอิงวันที่รัน ผ่านไปหลายวันกราฟจะเลื่อนออกนอกช่วง 30 วัน ให้สร้างใหม่ด้วย

  ```powershell
  go run ./cmd/seed -reset-logs
  ```

  ลบเฉพาะ `detection_logs` และไฟล์เสียงที่ขึ้นต้นด้วย `seed-` (hard delete) แล้วสร้างใหม่
  ข้อมูลจริงจากอุปกรณ์ไม่ถูกแตะ รูปแบบข้อมูลเหมือนเดิมทุกครั้ง (random seed คงที่)

### กันรันผิดที่

- `APP_ENV=production` → หยุดทันที
- `DB_HOST` ต้องเป็น `localhost`, `127.0.0.1`, `::1` หรือ `postgres` ถ้าตั้งใจใส่ลงฐานข้อมูลเครื่องอื่น
  (เช่นเครื่องทดสอบของทีม) ให้เพิ่ม `-allow-remote-db` — อย่าใช้กับฐานข้อมูลที่มีข้อมูลผู้ป่วยจริง

### ลบข้อมูลตัวอย่างทั้งหมด

ฐานข้อมูลตอนพัฒนาลบทิ้งทั้ง volume ได้ง่ายที่สุด (ข้อมูลทุกอย่างในฐานจะหายด้วย)

```powershell
docker compose down -v
```
